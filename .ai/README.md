# Shared agent context

Start with the root [AGENTS.md](../AGENTS.md), current
[English investment specification](specs/099-english-investment-workspace.md) and
[project documentation](../docs/README.md).

Earlier discovery notes and specifications are historical records from the original
collaborator's personal application. Preserve them in their original language; do
not treat archived account/project identifiers or old approval statements as current
permissions. Current instructions, documentation, code comments and new specs are English.

Record implementation state, confirmed decisions and unresolved questions precisely.
Maintain one source of truth for each current topic and link it from other entry points.
Keep code and financial behavior separate from historical intent. Never include secrets
or financial backups in agent documentation. Use focused, reviewable specifications.
